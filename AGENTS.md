# Diretrizes do Projeto - UseSol Energia

## Controle de Versão e Envio ao GitHub
- **NUNCA faça `git push` automaticamente.**
- Todas as alterações de código devem ser feitas e validadas **exclusivamente em ambiente local** (`localhost:5173`).
- O usuário deve testar e aprovar as mudanças localmente antes de qualquer código ser enviado para o repositório remoto no GitHub.
- Só execute `git push` quando o usuário confirmar explicitamente (ex.: *"pode subir pro github"*, *"está aprovado, pode commitar e enviar"*).
