# Regra de Git e Envio para o GitHub

- **NUNCA executar `git push` automaticamente.**
- Todas as alterações de código devem ser mantidas e testadas apenas localmente (`localhost`).
- O usuário precisa validar e testar as mudanças visual e funcionalmente antes de qualquer envio ao repositório remoto.
- Só realize `git push` quando o usuário solicitar ou autorizar expressamente (ex: "pode subir", "envie para o github", "faça o push").
